# Domain Glossary (CONTEXT.md)

Shared domain concepts and seams for the `aniketpatidar/skills` repository.

## Terms

### Skill Module
A discrete capability directory containing a `SKILL.md` entrypoint. Presents an interface (metadata frontmatter and contract) and an implementation (instructions, invariants, and templates).

### Resume Orchestrator Module
The primary interface (`SKILL.md`) that drives the interview loop, orchestrates candidate interaction, and defines invariant formatting rules.

### Action Vocabulary Module
The standalone lexical reference (`ACTION-WORDS.md`) categorizing strong action verbs by professional discipline.

### Resume Samples Module
A single consolidated reference file (`REFERENCE.md`) holding verbatim domain samples (Tech/CS, Engineering, General, Specialized) and layout templates (bullet-point and narrative).
