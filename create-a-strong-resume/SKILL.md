# Create a Strong Resume

Resume summarize abilities, education, experience. Show strongest skills, stand out from other candidates. Goal: get interview. Tailor to target job. Highlight skills employer value.

## Workflow

1. **Parse Input**: If user provides PDF/DOCX, extract text to markdown first.
2. **Interview**: User want to write, refine, or modify resume → relentlessly interview user to sharpen context. Ask 1 focused question at a time: extract metrics, tools, scale, impact.
3. **Target**: Find target job, industry, required skills. Match employer needs.
4. **Structure**: Education first for students/new grads. Experience first for experienced candidates. Reverse chronological order always.
5. **Bullets**: Lead with strong verbs from [ACTION-WORDS.md](ACTION-WORDS.md). Quantify results: *Accomplished [X], measured by [Y], by doing [Z]*.
6. **Review**: Follow Quick Tips, Do's, and Don'ts below. Kill passive voice, typos, bad formatting.

Quick Tips:

## RESUME LANGUAGE SHOULD BE:

- Specific rather than general
- Active rather than passive
- Written to express not impress
- Articulate rather than “flowery”
- Fact-based (quantify and qualify)
- Written for people who / systems that scan quickly

## TOP FIVE RESUME MISTAKES:

1. Spelling and grammar errors
2. Missing email and phone information
3. Using passive language instead of “action” words
4. Not well organized, concise, or easy to skim
5. Not demonstrating results

## DON’T:

- Use personal pronouns (such as I or We)
- Abbreviate
- Use a narrative style
- Use slang or colloquialisms
- Include a picture
- Include age or gender
- List references
- Start each line with a date

## DO:

- Be consistent in format and content
- Make it easy to read and follow, balancing white space
- Use consistent spacing, underlining, italics, bold, and capitalization for emphasis
- List headings (such as Experience) in order of importance
- Within headings, list information in reverse chronological order (most recent first)
- Avoid information gaps such as a missing summer
- Be sure that your formatting will translate properly if converted to a .pdf
